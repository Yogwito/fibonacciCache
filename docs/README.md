# docs/

Esta carpeta guarda los entregables del informe.

## Contenido

- **`enunciado.pdf`**: enunciado del taller.
- **`informe.pdf`**: informe final con la salida del programa, la tabla del inventario de claves, los 3 diagramas de flujo con su comparación y las respuestas a todas las preguntas.
- **`diagramas/`**: los 3 diagramas de flujo (sin caché, con caché y expiración, con memoización).
- **`respuestas.md`**: análisis de la parte 3, respuestas a las preguntas y tabla del inventario.
- **`salida_programa.txt`**: salida completa de `python taller_fib.py`.
